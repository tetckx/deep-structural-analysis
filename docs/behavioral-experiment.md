**性能验证（第四轮，重构后损失审计）**：117 项机制对照原版覆盖率 107/117（91.5%）——10 项丢失中 7 项为零损失（术语改名/功能等价/过度设计删除：Auto-degradation、信息缺失、Focused-depth、工具选择、敌对测试并入攻击循环、盲点验证在合成阶段保留、过度抽象化在 trauma-sensitive 扩展保留）；3 项有实质损失——**数据依赖审计（中等，已补回元认知补充检查）**、混合环节归因（轻微，执行者可自然判断主导侧）、维度覆盖（轻微，反惯性纪律部分替代）。**最终实质损失：0 项中等 + 2 项轻微（有替代机制）。**

**验证性质声明（第五轮，外部攻击修订——回应"行为实验=自指循环"指控）**：本行为实验标准存在两个层次，需明确区分——
- **执行性筛选（有效）**：行为实验测的是机制在"无刻意强制时的自然使用率"——校准检查×10 被文档明确要求但实战零痕迹（证明提示词遵从性不是万能的，机制真的会被跳过），据此删除；触发守卫实战有痕迹（自然使用），据此保留。**此层次测"机制是否被执行"，可观察、可验证，不是循环论证。**
- **有效性证明（不成立）**："被执行"≠"有效"——触发守卫被使用，但无人证明使用它让分析变好了。**本实验标准不能证明被保留机制的效力，只能筛选从未被使用的机制。**
- **保留机制的有效性证据**：只有攻击循环协议有外部性证据（五轮对攻中用户的人类判断参与，元认知前置协议被真实摧毁）；其余保留机制的有效性**未经独立验证**——这是已知局限，不是已验证的事实。
- **机制总数未降的承认**：v1.9.0 精简只压缩表述、未删机制本体（机制入库协议禁止）——机制总数 40+ 未变；分层协议将大部分降为第二层触发式（"未触发不执行"），但**第一层必跑机制数是否在 5-9 容量内，未经清点验证**——此点待实测。

**本说明自身同样不豁免于攻击**——若未来攻击证明"行为证据"标准本身有缺陷（"未执行≠无用"），本精简版应重新评估。附属层删除的文件如未来场景需要，可从 git 历史恢复。
