# 决策记录（Agent Notes 式）

> 规则：每条决策记录含【状态】（active/superseded）+【日期】+【背景】+【决策】+【放弃了什么】+【验证要求】。
> 与 UPDATELOG 的分工：UPDATELOG 记录"版本变更了什么"；本目录记录"为什么这样设计"。

## 决策 001：立场征集协议化（2026-08-15）

- 【状态】active
- 【背景】v1.9.2 引入"Phase 1.5 立场切换"（AI 执行利益相关方清单 → 每立场三问 → 模拟深度标注）。五轮进攻性对攻暴露：AI 模拟"资本立场"产出的只是知识库标签的重新排列（符号翻转，无信息增量）——发现权属于有真实立场的人（用户），不属于模拟立场的分析者。
- 【决策】Phase 1.5 从"AI 角色扮演流程"改为"向用户征集立场的交互协议"：向用户征集立场（核心动作，不可跳过）→ 记录用户视角（真实立场）→ AI 补充候选（显式声明"组织工具，不是发现"）→ 差异分析 → 不可通约性识别 → 模拟深度标注。无用户参与时降级为"视角审计"，不得伪装看过所有立场。
- 【放弃了什么】放弃了"AI 能通过角色扮演获得信息增量"的假设——AI 模拟立场只能重新排列已知知识，不能创造新信息。
- 【验证要求】实战中：用户提供真实立场后，分析产出是否包含"AI 单立场无法发现"的结构；无用户参与时，是否诚实标注"发现能力受限"而非伪装全面。

## 决策 002：攻击循环重写（2026-08-15）

- 【状态】active
- 【背景】原攻击循环要求"至少一个真实或模拟的相反立场"（强制攻击）。但 attack-survivors.md 已记录"AI 可执行独立攻击已被推翻（同一模型模拟对立 = 共享盲区）"——机制要求 AI 执行它自己证明无效的自我检验；"反证前置"同样是符号翻转（AI 列反证 = 从知识库检索反例，与生成支持证据是同一认知过程的镜像）。
- 【决策】删除"反证前置"与"强制攻击"；改为"暴露靶子 + 邀请真实攻击 + 修订痕迹 + 承认局限"——攻击执行者是用户不是 AI；无用户参与时标注"未接受真实外部攻击，发现能力受限"；强度可调移交用户。
- 【放弃了什么】放弃了"AI 自我攻击能提高正确性"的承诺——自我检验不能作为正确性保证机制（幸存者 2），模拟攻击不能发现共同盲区（幸存者 1 的边界）。
- 【验证要求】实战中：用户真实攻击是否改变分析结论（修订痕迹可验证）；无用户参与时是否诚实降级。

## 决策 003：收敛协议并入 Part A（2026-08-14）

- 【状态】active
- 【背景】Part A 执行摘要是快照式（核心发现/置信度/分歧/盲点），缺"待验证信号（观察窗口）"与"分析边界"两个时间维度元素。
- 【决策】Part A 新增"待验证信号"+"分析边界"——仅当分析含可验证判断时输出待验证信号（防表演化）。
- 【放弃了什么】放弃了"盲点清单可覆盖待验证信号"的假设——盲点是系统性不可见，待验证信号是明确观察窗口，两者不同。
- 【验证要求】交付的分析是否都带观察窗口（含可验证判断时）与分析边界。

## 决策 004：行为实验精简（2026-08-05~08-08，v1.9.0）

- 【状态】active
- 【背景】1.8.0 期间机制数超 40 项"必须执行"——超出单次分析可靠执行容量（5-9 项），"知识-执行分离"根因从纪律问题变为容量问题。
- 【决策】按实战输出痕迹（行为证据）精简：保留 20 项实战机制（触发守卫/历史强制/反惯性/推演四查/置信度/攻击循环等），删除校准检查×10（内省不可验证）、语言规则 21 行（伪需求）等。精简只压缩表述、不删机制本体；机制分层协议将大部分降为第二层触发式。
- 【放弃了什么】放弃了"文档要求 = 被执行"的假设（行为实验证明机制真的会被跳过）；放弃了校准检查（内省不可验证）。
- 【验证要求】行为实验只能筛选"从未被使用的机制"，不能证明被保留机制有效——保留机制有效性未经独立验证是已知局限（见 behavioral-experiment.md 验证性质声明）。
